Chrome desktop setup

You found the right menu.

If Chrome offers a desktop shortcut instead of the usual app install, use the option already visible in your menu:

  1. Click Chrome’s ⋮ three-dot menu in the top-right.
  2. Point to Cast, save, and share.
  3. Click Create shortcut… — it is the option just below “Open in Muse.”
  4. Name it D.A.B. 3D Quote Calculator, then click Create. If Chrome offers Open as window, turn that on first.
  5. Use the new desktop icon whenever you want the calculator.

Nothing is wrong with your computer. If Chrome does not show its native install prompt, the desktop shortcut steps below give you the same standalone app window.
